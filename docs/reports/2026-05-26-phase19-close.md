# Phase 19 close — Goal convergence controller

**Date:** 2026-05-26
**Trigger:** `tmp/phase19-goal-convergence-controller-plan.md`
**Harness range:** `93642e6` -> Phase 19 close package commit
**Scope tag:** milestone

Phase 19 adds a DB-backed convergence controller for bounded coding-agent goal
loops. It records frozen goal scope, attempts, review cycles, findings,
close checks, and convergence decisions, then exposes the workflow through CLI
and MCP surfaces.

Out of scope: autonomous worker scheduling, semantic finding clustering,
dashboard mutation UI, raw MCP shell execution, external issue tracker sync,
and automatic merge.

## Implemented Surface

- Schema v16 tables: `goal_sessions`, `goal_attempts`,
  `goal_review_cycles`, `goal_findings`, `goal_close_checks`, and
  `goal_convergence_decisions`.
- `GoalRepository` for goal sessions, attempts, review cycles, deduped
  findings, finding classification/fix/defer, close checks, and decision audit.
- `ConvergenceService` with deterministic decisions: `continue`,
  `needs_fix`, `needs_classification`, `close_ready`, `closed`, `diverging`,
  `budget_exhausted`, `escalate`, and `cancel`.
- Finding lifecycle helpers, scope classifier, review mode sequencing, and
  backlog deferral for out-of-scope follow-ups.
- `harness goal` CLI covering start/list/status, attempts, findings, review
  cycles, close checks, convergence evaluation, close, and cancel.
- MCP goal read/mutation/dangerous tools with idempotency, permission checks,
  confirmation handling, operation audit, redaction, and `goal_id` metadata.
- Optional `goalId` linking for MCP `run.start`, `review.auto`,
  `rerun.start`, and `review.process`, including project/repo/domain boundary
  validation.
- Review proposal import into goal cycles/findings, including negative review
  decisions with no required changes becoming an in-scope P1 blocker.
- Simulated goal-loop fixture matrix covering converging, diverging,
  out-of-scope defer, unknown classification, and budget exhaustion paths.
- `AGENTS.md` goal convergence operating rules.
